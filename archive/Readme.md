# Архив проекта

Данная папка содержит резервные и устаревшие версии компонентов проекта OmegaBot.

Файлы здесь не используются в текущей рабочей конфигурации робота.
Они сохранены для возможного дальнейшего развития проекта или возврата к предыдущим вариантам архитектуры.

---

## labirinth_client.cpp

Старый клиент управления роботом и получения данных с Raspberry Pi.

Использовался в ранней версии архитектуры:
- ПК выступал как отдельный клиент;
- подключался к Raspberry Pi через TCP;
- предназначался для ручного управления и обмена сообщениями.

В текущей версии заменён на графический операторский интерфейс (`operator_ui`).

---

## video_client.cpp

Старая программа просмотра видеопотока.

Предназначалась для отдельного подключения ПК к видеосерверу робота.

В текущей версии не используется:
- видеопоток обрабатывается через `camera_bridge.py`;
- отображение видео выполняется непосредственно в операторском интерфейсе.


---

## labirinth_server_with_joystick.cpp

Экспериментальная версия сервера управления роботом с поддержкой USB-геймпада.

Предполагалось:
- подключение джойстика к ПК, переправка команд через Raspberry Pi;
- обработка команд управления непосредственно на верхнем уровне робота.

В текущей архитектуре управление выполняется:
ПК → операторский интерфейс → TCP → Raspberry Pi → Arduino.


## Текущая рабочая архитектура

Актуальные компоненты находятся в корне репозитория:

- `operator_ui` — интерфейс оператора;
- `labirinth_server.cpp` — сервер управления на Raspberry Pi;
- `camera_bridge.py` — передача видео и запись архива;
- `str02-controller.ino` — программа Arduino нижнего уровня.

Изменения в текущую систему следует вносить только в эти компоненты, а не тратить время на те, что находятся здесь
