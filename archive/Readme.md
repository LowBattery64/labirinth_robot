# Архив проекта OmegaBot

В этой папке собраны прежние и экспериментальные реализации, сохранённые для справки и возможного восстановления старых подходов. Файлы архива не входят в штатный путь запуска системы из ветки `Prod`.

Перед изменением или запуском архивного компонента проверь его совместимость с текущими протоколами, прошивкой Arduino и операторским приложением.

## Содержимое

### `camera_bridge.py`

Старая реализация моста между сетевым источником камеры и клиентом видеопотока. Поддерживала передачу изображения и функции записи видео.

В текущей конфигурации с USB-камерой используется `usb_camera_server.cpp` в корне репозитория. Архивный Python-скрипт не следует путать с актуальным сервером USB-камеры.

### `labirinth_client.cpp`

Старая консольная программа-клиент для подключения к Raspberry Pi по TCP и отправки команд управления/получения сообщений.

В основной конфигурации управление выполняется через графическое приложение из каталога `operator_ui`.

### `labirinth_server_with_joystick.cpp`

Экспериментальная версия сервера с поддержкой USB-геймпада на стороне верхнего уровня. Сохранена для изучения старого подхода к обработке команд и джойстика.

Не является сервером, который запускает актуальный скрипт.

### `video_client.cpp`

Старая отдельная программа для просмотра видеопотока с робота. В актуальной конфигурации просмотр видео встроен в `operator_ui`.

### `video_server(1).cpp`

Предыдущая реализация видеосервера. Сохранена для сравнения с текущим `usb_camera_server.cpp`; не используется скриптом `scripts/start_usb_camera_robot.sh`.

### `motorcortex_1.crt`

Файл сертификата из прежней конфигурации. Он оставлен как архивный артефакт; не копируй его в рабочую конфигурацию и не считай актуальным без проверки назначения, срока действия и соответствия используемому оборудованию.

## Текущая рабочая конфигурация

Для обычной работы ориентируйся на следующие компоненты в корне репозитория:

- `operator_ui` — графический интерфейс оператора;
- `labirinth_server.cpp` — TCP-сервер управления на Raspberry Pi;
- `usb_camera_server.cpp` — видеопоток и запись с USB-камеры;
- `str02-controller.ino` — прошивка платы нижнего уровня;
- `scripts/start_usb_camera_robot.sh` и `scripts/stop_usb_camera_robot.sh` — запуск и остановка серверов.

Для запуска на Raspberry Pi см. [инструкцию по скриптам](../scripts/README.md).

## Важно

- Архивные файлы не синхронизируются автоматически с текущей архитектурой.
- Старые комментарии, адреса, порты и форматы команд могут не соответствовать текущей версии.
- Не запускай архивные серверы одновременно с рабочими: они могут использовать те же порты или последовательный порт Arduino.
- Изменения рабочей системы вноси в актуальные компоненты, а не в архив, если цель — изменить поведение текущего робота.
