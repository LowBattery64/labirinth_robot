# OmegaBot — телеуправление и видеосвязь

Документация текущей версии проекта: запуск, архитектура, датчики, логи и дальнейшие задачи.

## Сеть

| Устройство | Адрес |
|---|---|
| Raspberry Pi 3B | 10.109.150.232 |
| TrackingCam3 | 10.109.150.34 |
| ПК оператора | 10.109.150.107 |

- TCP 5000 — управление и телеметрия.
- TCP 5001 — видео.
- WebSocket 5557 — поток TrackingCam3.

## Компоненты

`str02-controller.ino` — прошивка ARP-DEK-STR-02. Управляет двумя моторами, принимает F/B/L/R/S, считывает передний IR, три ультразвуковых датчика и два энкодера, отправляет телеметрию каждые 200 мс. Watchdog — 500 мс. Переднее движение блокируется при препятствии на расстоянии 25 см или меньше. Опрос TrackingCam на Arduino сейчас отключен.

`labirinth_server.cpp` — Raspberry Pi сервер. TCP 5000, USB Serial `/dev/ttyUSB0`, 115200 бод. Передает команды Arduino, принимает телеметрию, пересылает ее ПК и пишет `robot.log` и `telemetry.csv`.

`camera_bridge.py` — видеомост TrackingCam3 → WebSocket 5557 → Raspberry Pi → TCP 5001 → ПК. Может записывать видео через `--record-to`.

`operator_ui/` — Qt 6 приложение оператора. Управление W/A/S/D и стрелками, STOP/Space, видео, телеметрия, состояние соединения и FPS.

## Полный порядок запуска

### 1. Arduino

1. Подключить ARP-DEK-STR-02 к ПК по USB.
2. Открыть `str02-controller.ino` в Arduino IDE.
3. Выбрать `Arduino Mega`.
4. Загрузить прошивку.
5. Отключить USB от ПК.
6. Подключить USB платы к Raspberry Pi.
7. В текущей конструкции Raspberry Pi питается от платы робота.

### 2. Raspberry Pi

Подключиться:

    ssh raspberry@10.109.150.232

Перейти в репозиторий:

    cd ~/labirinth_robot
    git pull

Проверить Serial:

    ls /dev/ttyUSB*

Ожидается `/dev/ttyUSB0`.

Скомпилировать и запустить сервер:

    g++ -std=c++17 labirinth_server.cpp -o labirinth_server
    ./labirinth_server

Оставить этот SSH-сеанс запущенным.

### 3. Видеомост

Во втором SSH-сеансе:

    ssh raspberry@10.109.150.232
    cd ~/labirinth_robot

Если OpenCV еще не установлен:

    sudo apt update
    sudo apt install python3-opencv

Подготовить USB-флешку:

    mkdir -p /media/raspberry/76E8-CACF/omegabot_recordings

Запустить:

    python3 camera_bridge.py --camera-ip 10.109.150.34 --record-to /media/raspberry/76E8-CACF/omegabot_recordings

В текущей диагностической версии TrackingCam3 может не публиковать видео до открытия:

    http://10.109.150.34/

Если видео не появляется, открыть эту страницу на ПК. Это временный обходной путь; необходимо найти способ запускать поток без браузера.

### 4. Операторское приложение

На Windows из корня репозитория:

    cmake -S operator_ui -B operator_ui/build -G "Visual Studio 17 2022" -A x64
    cmake --build operator_ui/build --config Release

Запустить `operator_ui/build/Release/OmegaBotOperator.exe`.

Приложение подключается к `10.109.150.232:5000` и `10.109.150.232:5001`.

## Управление

| Клавиша | Действие |
|---|---|
| W / ↑ | вперед |
| S / ↓ | назад |
| A / ← | влево |
| D / → | вправо |
| Space | стоп |

Команда сохраняется после нажатия. Отпускание клавиши не останавливает робота.

## Датчики и телеметрия

Пример строки:

    T,IR,0,US,120,85,90,ENC,123,119,SAFE,0,CMD,F,WD,0

- `IR` — передний ИК-датчик.
- `US` — центр, лево, право.
- `ENC` — импульсы левого и правого энкодеров.
- `SAFE` — состояние передней защиты.
- `CMD` — последняя команда.
- `WD` — watchdog.

TrackingCam на Arduino сейчас не опрашивается.

## Логи и записи

При запуске `labirinth_server` из `~/labirinth_robot` создаются:

    ~/labirinth_robot/robot.log
    ~/labirinth_robot/telemetry.csv

`robot.log` содержит события сервера и команды. `telemetry.csv` содержит временные отметки и строки телеметрии.

Видео записывается в:

    /media/raspberry/76E8-CACF/omegabot_recordings

Проверка:

    ls -lh /media/raspberry/76E8-CACF/omegabot_recordings

Журнал оператора пока существует только в памяти GUI.

## Взаимодействие

ПК → TCP 5000 → `labirinth_server` → USB Serial → `str02-controller.ino` → моторы.

`str02-controller.ino` → USB Serial → `labirinth_server` → TCP 5000 → ПК.

TrackingCam3 → WebSocket 5557 → `camera_bridge.py` → TCP 5001 → ПК.

## Что уже работает

- базовое телеуправление;
- телеметрия;
- передача видео;
- запись видео;
- watchdog;
- передняя ультразвуковая защита.

2. Добавить в интерфейс управление качеством видео.
3. Необязательно: добавить кнопку REC для запуска и остановки записи.
4. Реализовать автоматическое поведение при потере связи и возврат в зону связи согласно ТЗ.
5. Рассмотреть отдельное питание Raspberry Pi — это конструкционный вопрос.
6. Сохранять журнал оператора на ПК и синхронизировать его по времени с логами, телеметрией и видео.
7. Реализовать подсчет желтых меток, сбор данных в зонах меток и автономный осмотр зон без связи.

## Ограничения

- Raspberry Pi: `10.109.150.232`.
- TrackingCam3: `10.109.150.34`.
- Serial: `/dev/ttyUSB0`, 115200.
- Управление/телеметрия: TCP 5000.
- Видео: TCP 5001.
- Камера: WebSocket 5557.
- Watchdog: 500 мс.
- Передняя защита: 25 см.
- После отключения ПК текущий `labirinth_server` завершает сессию; для нового подключения его нужно запустить снова.
